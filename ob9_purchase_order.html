รายการสั่งซื้อ (Admin เท่านั้น)

รวมสถานะการสั่งซื้ออะไหล่ (MEMO → RO → RFS) จากหน้า Dashboard → Spare Parts มาไว้ที่เดียว พร้อมรายการสั่งซื้ออื่นๆ ที่ไม่ใช่อะไหล่ในแคตตาล็อก (เช่น เครื่องมือ, บริการภายนอก)

📦 สถานะสั่งซื้ออะไหล่ (จากระบบ Spare Parts เดิม)

แสดงเฉพาะอะไหล่ที่มีการเริ่มขั้นตอนสั่งซื้อแล้ว (ติ๊ก MEMO/RO/RFS ไว้ในหน้า Dashboard → Spare Parts) กดที่ป้าย MEMO/RO/RFS เพื่อเปลี่ยนสถานะได้จากหน้านี้เลย ข้อมูลจะซิงก์กับหน้า Dashboard อัตโนมัติ (ถ้าต้องการเริ่มสั่งซื้ออะไหล่ตัวใหม่ที่ยังไม่มีในลิสต์นี้ ให้ไปเริ่มที่หน้า Dashboard → Spare Parts ก่อน)
เครื่องจักรระบบ / Positionชิ้นส่วนStock คงเหลือ MEMORORFS

➕ รายการสั่งซื้ออื่นๆ

สำหรับของที่ไม่ใช่อะไหล่ในแคตตาล็อกเดิม เช่น เครื่องมือช่าง, อุปกรณ์เซฟตี้, บริการซ่อมจากผู้รับเหมาภายนอก
รายการจำนวนราคารวมผู้จำหน่ายสถานะหมายเหตุ
