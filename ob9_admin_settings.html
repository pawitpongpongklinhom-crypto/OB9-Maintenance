ตั้งค่าสิทธิ์การเข้าใช้งาน (Admin เท่านั้น)

กำหนดว่าพนักงานคนไหนเข้าใช้โมดูลไหนได้บ้าง — Executive Summary / Work Order / Daily Inspection

➕ เพิ่มพนักงานทีละคน

📁 อัปโหลดรายชื่อด้วยไฟล์ Excel

คอลัมน์ในไฟล์ (แถวแรกเป็นหัวตาราง): ชื่อพนักงาน, รหัสพนักงาน, Executive, WorkOrder, Inspection — ใส่ Y หรือ 1 ในคอลัมน์สิทธิ์ที่ต้องการอนุญาต (เว้นว่างหรือ N = ไม่อนุญาต) รายชื่อที่อัปโหลดจะเพิ่มเข้าไปในตารางด้านล่าง (ถ้ารหัสพนักงานซ้ำของเดิมจะอัปเดตสิทธิ์แทน)

📋 รายชื่อพนักงานที่มีสิทธิ์เข้าระบบ (0 คน)

ชื่อพนักงาน รหัสพนักงาน Executive Work Order Inspection
ยังไม่มีรายชื่อพนักงาน — เพิ่มด้วยฟอร์มด้านบน หรืออัปโหลด Excel
